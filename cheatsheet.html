Cheat sheet

Every recipe on one page, plus which test or model to use, sentence templates for the interpretation, common errors and an exam checklist.

Replace dataset, y, x, z and group with your own names. The slides have worked examples with their output.

Start

# Install once per computer, then put the # back in front
# install.packages(c("dplyr", "lmtest", "car", "margins", "nnet"))

# Load the packages, in every new session
library(dplyr) # mutate(), case_when()
library(lmtest) # bptest()
library(car) # vif()
library(margins) # margins()
library(nnet) # multinom()

# Where is R looking, and is the data file there?
getwd()
list.files()

# Read the data (all in one column? use read.csv2() instead)
dataset <- read.csv("file.csv")

Inspect

# Variable names, rows and columns, types, first rows
names(dataset)
dim(dataset)
str(dataset)
head(dataset)

# Every value with its count, NA included
table(dataset$x, useNA = "ifany")

# A max of 99 or 999 is a missing-value code
summary(dataset$x)

# All the distinct values, sorted
sort(unique(dataset$x))

Clean (always into a new variable, then check it)

# Keep a valid range (here 0 to 10), everything else becomes NA
dataset$x_clean <- ifelse(
  dataset$x >= 0 & dataset$x <= 10,
  dataset$x,
  NA
)

# Set the missing-value codes to NA
dataset$x_clean <- ifelse(dataset$x %in% c(77, 88, 99), NA, dataset$x)

# Binary: 4 becomes 1, 1 to 3 become 0, anything else NA
dataset$x_bin <- ifelse(
  dataset$x == 4,
  1,
  ifelse(dataset$x %in% c(1, 2, 3), 0, NA)
)

# Several categories, base R: start with NA, then fill each range
dataset$x_cat <- NA
dataset$x_cat[dataset$x >= 0 & dataset$x <= 3] <- 1
dataset$x_cat[dataset$x >= 4 & dataset$x <= 6] <- 2

# Several categories, dplyr: TRUE ~ NA_real_ = everything else is NA
dataset <- dataset |>
  mutate(
    x_cat = case_when(
      x <= 3 ~ 1,
      x >= 4 & x <= 6 ~ 2,
      TRUE ~ NA_real_
    )
  )

# Categories with labels (the first level is the reference in models)
dataset$x_f <- factor(
  dataset$x,
  levels = c(1, 2),
  labels = c("Man", "Woman")
)

# Keep one group only
dataset_fr <- subset(dataset, cntry == "FR")

# Check: old values in the rows, new values in the columns
table(dataset$x, dataset$x_clean, useNA = "ifany")

Which test or model?

Start from the question, then look at the type of each variable. Y is the dependent variable (what you explain), X the independent variable.

1. What type is each variable?

Type Values Examples from the labs
Nominal categories without an order (2 categories = binary, or dummy) gndr, cntry, voted_2024, far_right
Ordinal categories that follow an order hincfel (1–4), swd (1, 2, 4, 5)
Continuous values that mean something in reality agea, eduyrs, lrscale (0–10)

An ordinal variable can be treated as nominal or as continuous (Lectures 2 and 4). The labs treat a 0–10 scale as continuous and recode it into categories when a model needs them (left_right_3cat).

2. One variable

Type Describe with
Nominal or ordinal table(), prop.table(table()) * 100, barplot()
Continuous mean(), median(), sd(), summary(), hist()
Is the mean different from a value? one-sample t-test: t.test(dataset$x, mu = 0.4) (Lecture 6)
How precise is the sample mean? 95% confidence interval: t.test(dataset$x)$conf.int

3. Two variables

Y X Show Test R
nominal nominal crosstab with row or column % chi-square chisq.test(table(dataset$x, dataset$y))
continuous binary the two group means, boxplot() t-test t.test(y ~ x, data = dataset)
continuous 3+ categories group means with aggregate() OLS with a factor lm(y ~ factor(x), data = dataset)
continuous continuous scatter plot correlation, or OLS cor.test(dataset$x, dataset$y), lm(y ~ x, data = dataset)
binary continuous mean of X in each group of Y t-test, with the roles swapped t.test(x ~ y, data = dataset) (Lab 3: age by satisfaction)
  • t.test() needs a group with exactly 2 values. With 3 or more categories, use lm() with factor(): each coefficient compares a category with the reference category.
  • An OLS on a binary factor() gives the same difference in means as the t-test (Lecture 8: “similar to a t-test”). The p-values differ a little because t.test() doesn’t assume equal variances.
  • A chi-square test gives no direction: read the percentages for that.
  • Bivariate tests are a first look, not enough for robust conclusions. To take other causes into account, use a regression with control variables (Lectures 4 and 9).

4. Several independent variables: which regression?

Choose by the type of Y:

Y Model R Interpret
continuous (incl. a 0–10 scale) OLS lm(y ~ x1 + x2, data = dataset) coefficient = change in Y when X increases by one unit
binary (0/1) logistic regression (logit) glm(y ~ x1 + x2, data = dataset, family = binomial) sign only, size from summary(margins(logit)) in percentage points
nominal, 3+ categories multinomial logit multinom(y ~ x1 + x2, data = dataset, trace = FALSE) sign only, each category against the reference category

A ranking such as hincfel as Y: treat it as continuous (OLS) or recode it into categories (logit or multinomial logit).

5. What to add to the model

If … Add R
X is categorical dummies against a reference category factor(x)
a third variable could cause both X and Y (spurious effect) control variables + z1 + z2
observations are grouped (respondents in countries) fixed effects: estimates within groups + factor(cntry)
the effect of X depends on Z (moderation) interaction x * z
one group only (e.g. France) a subsample subset(dataset, cntry == "FR")
floor or ceiling effect (Lecture 8, not in the labs) log of X (X > 0) log(x)
the effect changes direction as X grows (Lecture 8, not in the labs) X and X squared x + I(x^2)

6. Checks after an OLS (Lecture 9)

Problem Check If it is there
Outliers hist(), plot(), summary() remove them
Heteroskedasticity plot(model$fitted.values, model$residuals), bptest(model) robust standard errors, e.g. coeftest(model, vcov = hccm(model)) (not in the labs)
Multicollinearity vif(model) below 10: not a concern (the course does nothing about it)

Describe one variable

# Categorical: counts, percentages, bar chart
table(dataset$x)
prop.table(table(dataset$x)) * 100
barplot(table(dataset$x))

# Continuous: centre and spread (na.rm = TRUE skips the NAs)
mean(dataset$x, na.rm = TRUE)
median(dataset$x, na.rm = TRUE)
sd(dataset$x, na.rm = TRUE)
summary(dataset$x)

# Histogram with one bar per value on a 0-10 scale
hist(dataset$x, breaks = seq(-0.5, 10.5, by = 1))

Two variables

# Categorical x categorical: crosstab, row %, chi-square test
tab <- table(dataset$x, dataset$y)
prop.table(tab, margin = 1) * 100 # margin = 2: column %
chisq.test(tab)

# Continuous y by a binary group: group means, t-test, box plot
aggregate(y ~ group, data = dataset, FUN = mean)
t.test(y ~ group, data = dataset)
boxplot(y ~ group, data = dataset)

# Continuous x continuous: r, r with its p-value, scatter plot
cor(dataset$x, dataset$y, use = "complete.obs")
cor.test(dataset$x, dataset$y)
plot(dataset$x, dataset$y)

Models

# OLS (continuous y): factor() for categorical predictors,
# + factor(cntry) = country fixed effects
model <- lm(y ~ x1 + factor(x2) + x3 + factor(cntry), data = dataset)
summary(model) # coefficients, p-values, R-squared
confint(model) # 95% confidence intervals
nobs(model) # N the model used (rows with NA are dropped)

# Heteroskedasticity: residuals against fitted values, then the test
plot(model$fitted.values, model$residuals)
abline(h = 0)
bptest(model) # H0: homoskedasticity

# Multicollinearity: below 10 is not a concern
vif(model)

# Logit (binary y): read only the sign of the coefficients
logit <- glm(
  y ~ x1 + factor(x2) + x3,
  data = dataset,
  family = binomial
)
summary(logit)

# Average marginal effects: change in probability (x 100 = points)
summary(margins(logit))

# Multinomial logit (3+ categories): reference = first level
mlogit <- multinom(
  y ~ x1 + factor(x2) + x3,
  data = dataset,
  trace = FALSE
)
round(coef(mlogit), 3) # one row per category against the reference

# Interaction: does the effect of x depend on z?
model_int <- lm(y ~ factor(z) * x + controls, data = dataset)

# Slope of x when z = 2: b_x + b_interaction
coef(model_int)[["x"]] + coef(model_int)[["factor(z)2:x"]]

Sentence templates

Wording from Prof. Bol’s slides and his correction of the sample midterm.

Output Write
Mean, median, SD “Given that the mean and the median are very close, the distribution is approximately symmetric” (or: “positively/right-skewed, due to the value …, which makes the mean higher than the median”). “The standard deviation is …, which is relatively low/high compared to the mean. The spread of the distribution is thus small/large.”
Group means “Men: …. Women: …. There is therefore no difference / a difference in the means, suggesting no association / an association between X and Y in this sample.”
cor() “There is a positive/negative, [strength] association between X and Y, so that the more X, the higher/lower Y.” Strength: |r| < 0.10 negligible, 0.10 weak, 0.30 moderate, 0.50 strong, 0.75 very strong.
chisq.test() “X² = …, df = …, p = …. The association is statistically significant at the 0.01 level, so we reject the null hypothesis of no association between A and B. The percentages show that …% of group 1 are …, against …% of group 2.”
t.test() “The mean of Y is … in group 0 and … in group 1 (t = …, p = …). The difference is statistically significant at the 0.05 level, so we reject the null hypothesis that the means are not different.”
Significance p < 0.01, 0.05 or 0.10: “statistically significant at the 0.01 / 0.05 / 0.10 level”. Above 0.10: “not statistically significant”.
Stars R’s summary(): *** < 0.001, ** < 0.01, * < 0.05, . < 0.1. The course’s tables: *** < 0.01, ** < 0.05, * < 0.10. Write the level in words.
lm(), continuous x “When X increases by one unit, Y increases/decreases by b, net of the control variables (statistically significant at the … level).”
lm(), factor() dummy “Y is b larger/smaller in [category] than in [reference category], net of the control variables.”
Constant “The value of Y when all the independent variables are 0.”
R² “The independent variables explain …% of the variance of Y.”
Fixed effects “With country fixed effects, the estimates are within countries.”
glm() coefficient “The coefficient is positive/negative, so X increases/decreases the probability that Y = 1.” Only the sign can be interpreted.
Marginal effect “When X increases by one unit, the probability that Y = 1 increases/decreases by AME × 100 percentage points.”
multinom() “Compared with [reference category], X increases/decreases the log-odds of [category] (b = …).” Only the sign can be interpreted.
Interaction “The effect of X is b_x for [reference group] and b_x + b_interaction for [other group]. The interaction is (not) statistically significant, so Z moderates / we cannot conclude that Z moderates the effect of X.”
bptest() “BP = …, p < 0.01: we reject homoskedasticity, so there is heteroskedasticity. Fix: robust standard errors.”
vif() “All VIFs are below 10, so multicollinearity is not a concern.”

A statistically significant effect is not always strong: also give the size.

Before you hand in

  • Did you load the right file, and do the numbers of rows and columns make sense?
  • Did you check every variable you use and turn its missing-value codes into NA?
  • Did you check every new variable with table()?
  • Are the categorical predictors in factor()?
  • Did you use the right percentages (row or column)?
  • Does each test match the types of the variables?
  • Does every result have a sentence in words?
  • Does the script run from top to bottom after Session > Restart R?
