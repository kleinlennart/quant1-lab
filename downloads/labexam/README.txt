# labexam: an RStudio project for the QM1 lab exam

1. Unzip this folder somewhere you can find it (not in Downloads, e.g. Documents/QM1/labexam).
2. Put the data from Moodle into `data/`: `ess.csv` and `anes_timeseries_2024_csv_20250808.csv`.
3. Double-click `labexam.Rproj`. RStudio opens with the working directory set to this folder.
4. Install the packages once (in the Console, not in your script):
   install.packages(c("dplyr", "lmtest", "car", "margins", "nnet"))
5. Rename `Lastname_Firstname_labexam.R` to your own name and fill it in.
6. Before you hand in: Session > Restart R, then run the whole script from the top.

Guide and cheat sheet: see the link you got with this zip.
