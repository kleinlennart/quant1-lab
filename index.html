The lab exam

Task “Write R code to perform a series of analyses on a dataset and interpret the results” (syllabus)
When Week 11, in class, at the normal lecture time; 2 hours
Weight 30% of the course grade
Allowed Any resources

You get a dataset and run an analysis from start to finish: clean the variables, describe them, test associations, estimate models, and say in words what the results mean. The lab sessions prepare you for it, and Lab 6 (week 12) goes through the correction.

How to use this guide

The pages follow the steps of an analysis, in the order you’d run them in the exam. Every section has the same four parts:

  1. Recipe: the general code, with placeholders (dataset, y, x, group). The exam dataset may not be one from the labs, so start from the recipe.
  2. Example from the labs: the lab code with its real output.
  3. How to read it: what the numbers mean, and a sentence you can adapt for your answer.
  4. Your turn: the labs’ own exercises. Write the code yourself before you open the solution. Recalling it yourself sticks better than rereading it.

The cheat sheet puts all the recipes on one page, to keep open during the exam.

An analysis in five steps

This is the workflow from the labs:

Step Question Typical commands Page
1. Inspect What values does the raw variable contain? Which codes mean “missing”? table(x, useNA = "ifany"), summary(x), sort(unique(x)) Start and clean
2. Clean Make a new variable; keep the original unchanged ifelse(), case_when(), factor() Start and clean
3. Verify Did the recode work? table(new, useNA = "ifany"), table(old, new) Start and clean
4. Describe What does the clean variable look like? table(), prop.table(), mean(), sd(), median(), hist() Describe one variable
5. Analyse Which test or model fits the variable types? chisq.test(), t.test(), cor(), lm(), glm() pages 3–5

Your variables Use Page

The data

The examples and exercises use the two datasets from the labs. The site uses small extracts with only the lab variables, and the values are unchanged:

  • anes_lab.csv: ANES 2024, US election survey, 5,521 respondents (Labs 1–3).
  • ess_lab.csv: European Social Survey round 11, 39,514 respondents in 23 countries (Labs 4–5).
  • students.csv: the student marks table from Lab 1.

In your own script, read the full files from Moodle instead, e.g. read.csv("anes_timeseries_2024_csv_20250808.csv") or read.csv("ess.csv"). The variable names are the same.
